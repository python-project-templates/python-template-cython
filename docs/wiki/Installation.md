## Pre-requisites

You need Python >=3.10 on your machine to install `python-template-cython`.

## Install with `pip`

```bash
pip install python-template-cython
```

## Install with `conda`

```bash
conda install python-template-cython --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `python-template-cython` from source](Build-from-Source).
